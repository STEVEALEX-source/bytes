# bytes

A tiny storage unit converter.

Paste a number, pick a unit, and instantly see the value in B, KB, MB, GB, TB, KiB, MiB, GiB, and TiB.

- Distinguishes decimal (KB/MB) from binary (KiB/MiB)
- Single HTML file, no dependencies
- Under 3 KB

## Use it

Just open `bytes.html` in any browser.

## Why

Most converters either mix up decimal and binary units or weigh 200 KB. This one doesn't.
